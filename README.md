# Recipe Finder 🍽️

A modern Recipe Finder web app built using HTML, CSS, and JavaScript.

Users can search for meals, view recipe details, ingredients, instructions, and watch video tutorials using data fetched from TheMealDB API.

---

## Features ✨

* Search recipes instantly
* Fetch live meal data from API
* View meal images and categories
* Detailed cooking instructions
* Ingredient + measurement list
* YouTube tutorial links
* Smooth scrolling interactions
* Responsive dark-themed UI

---

## Tech Stack 🚀

* HTML5
* CSS3
* Vanilla JavaScript
* TheMealDB API

---
